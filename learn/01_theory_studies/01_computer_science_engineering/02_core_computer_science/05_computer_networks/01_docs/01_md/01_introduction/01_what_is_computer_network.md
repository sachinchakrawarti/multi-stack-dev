# What is Computer Network?

## Definition

A **Computer Network** is a collection of two or more computers, servers, mobile devices, IoT devices, or other digital systems connected together to exchange data, share resources, and communicate using standard communication protocols.

The connection between devices can be established using **wired technologies** (such as Ethernet or Fiber Optics) or **wireless technologies** (such as Wi-Fi, Bluetooth, Cellular Networks, and Satellite Communication).

---

## Simple Definition

A computer network is a system that allows multiple devices to communicate and share information with each other.

---

## Real-Life Example

When you open a website:

1. Your laptop connects to your home Wi-Fi.
2. The Wi-Fi router connects to your Internet Service Provider (ISP).
3. The ISP forwards your request across multiple networks.
4. The web server receives your request.
5. The server sends the webpage back to your device.

This complete communication happens through computer networks.

# Main Components of a Computer Network

A computer network consists of several hardware and software components.

## 1. Devices (Nodes)

Devices connected to the network are called **nodes**.

Examples:

- Desktop Computer
- Laptop
- Smartphone
- Tablet
- Server
- Printer
- CCTV Camera
- IoT Device

---

## 2. Transmission Media

The medium through which data travels.

### Wired Media

- Ethernet Cable
- Fiber Optic Cable
- Coaxial Cable

### Wireless Media

- Wi-Fi
- Bluetooth
- Infrared
- Satellite
- Cellular Networks

---

## 3. Network Devices

These devices help manage communication.

Examples:

- Router
- Switch
- Hub
- Bridge
- Repeater
- Modem
- Wireless Access Point
- Firewall

---

## 4. Communication Protocols

Protocols are rules that allow devices to communicate correctly.

Common protocols include:

- TCP
- IP
- HTTP
- HTTPS
- FTP
- SMTP
- DNS
- DHCP
- SSH

---

## 5. Network Operating System

A Network Operating System manages network resources.

Examples:

- Windows Server
- Linux Server
- Ubuntu Server
- Red Hat Enterprise Linux

---

## 6. Network Services

Services provided over the network include:

- Email
- Web Hosting
- File Sharing
- Cloud Storage
- Authentication
- Database Access
- Remote Desktop

# Summary

A computer network is an interconnected system of devices that communicate and share resources using standardized communication protocols. It forms the backbone of modern computing, enabling services such as the Internet, cloud computing, online banking, streaming, communication, and enterprise systems. Understanding computer networks is the first step toward mastering networking concepts such as the OSI model, TCP/IP, routing, switching, security, cloud networking, and network administration.
