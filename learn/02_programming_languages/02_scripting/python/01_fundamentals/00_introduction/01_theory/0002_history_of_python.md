# History of Python

## 1. Introduction

Python is a popular, high-level, general-purpose programming language.

Python was created by **Guido van Rossum**.

Python was designed to be:

* Easy to read
* Easy to learn
* Simple to write
* Powerful
* Flexible
* Useful for many types of applications

Python development started in the **late 1980s**, and the first public version was released in **1991**.

---

# 2. Who Created Python?

Python was created by:

**Guido van Rossum**

Guido van Rossum is a Dutch programmer.

He started working on Python as a personal programming project.

He wanted to create a programming language that was:

* Simple
* Readable
* Practical
* Easy to use
* Powerful enough for real programming

---

# 3. When Was Python Created?

Python development began around:

**1989**

The first public release of Python was:

**1991**

So, Python has been developed and improved for many years.

---

# 4. Why Was Python Created?

Before Python, programmers commonly used languages such as:

* C
* C++
* Pascal
* ABC
* Perl
* Lisp

Many programming languages were powerful, but some were difficult for beginners to read and write.

Guido van Rossum wanted a language that could combine:

* Simplicity
* Readability
* Productivity
* Extensibility
* Powerful features

Python was created with these ideas in mind.

---

# 5. ABC Programming Language

An important influence on Python was the **ABC programming language**.

Guido van Rossum had worked at **CWI** in the Netherlands.

ABC was designed to make programming easier, especially for beginners.

Python took some ideas from ABC but also improved and changed many things.

Python was designed to be more practical and extensible.

---

# 6. Python Development Started

During the Christmas holidays of **1989**, Guido van Rossum started working on Python.

He worked on the project while at CWI in the Netherlands.

The project was originally created as a successor to the ABC programming language.

---

# 7. Why Is It Called Python?

The name **Python** did not come from the snake.

Guido van Rossum was a fan of the British comedy group:

**Monty Python**

He was watching the comedy series:

**Monty Python's Flying Circus**

when he was working on the language.

He wanted a name that was:

* Short
* Unique
* Interesting
* Easy to remember

So he chose the name:

**Python**

---

* Functions
* Classes

Python was already designed to be a high-level and readable language.

# 9. Python 0.9.0

The first public release was:

**Python 0.9.0**

**1991**

Python 0.9.0 included many features that are still important concepts in modern Python.

---

# 10. Python 1.0

Python **1.0** was released in:

**1994**

Python continued to grow and gain new users.

The language became more mature and useful for software development.

---

# 11. Python 2.0

Python **2.0** was released in:

**2000**

Python 2 introduced several important improvements.

Some notable improvements included:

* List comprehensions
* Garbage collection improvements
* Unicode support
* Better language features
* Improved standard library

Python 2 became widely used.

---

# 12. Python 2 Era

For many years, Python 2 was one of the most commonly used Python versions.

Many:

* Companies
* Developers
* Universities
* Projects
* Open-source communities

used Python 2.

However, Python 2 had limitations that eventually required a major improvement.

This led to Python 3.

---

# 13. Python 3

Python **3.0** was released in:

**2008**

Python 3 was designed as a cleaner and improved version of Python.

It introduced changes that were not fully backward compatible with Python 2.

This means:

```text
Python 2 code
      ↓
may not work directly
      ↓
Python 3
```

Developers often had to modify older Python 2 programs when moving to Python 3.

---

# 14. Why Was Python 3 Created?

Python 3 was created to improve the language and remove some old design problems.

The goals included:

* Cleaner language design
* Better consistency
* Better Unicode support
* Improved syntax
* Better long-term development

Python 3 became the future direction of Python.

---

# 15. Python 2 vs Python 3

A simple comparison:

| Feature                 | Python 2         | Python 3                |
| ----------------------- | ---------------- | ----------------------- |
| First major release     | 2000             | 2008                    |
| Modern development      | No               | Yes                     |
| `print`                 | Statement        | Function                |
| Unicode                 | More complicated | Better built-in support |
| Division behavior       | Different        | Improved                |
| Current learning choice | No               | Yes                     |

Example:

### Python 2

```python
print "Hello"
```

### Python 3

```python
print("Hello")
```

Today, new Python learners should learn **Python 3**.

---

# 16. End of Python 2

Python 2 officially reached the end of its life on:

**January 1, 2020**

After this date, the Python core development community stopped providing official Python 2 maintenance and security updates.

Python 3 is now the standard version for modern Python development.
