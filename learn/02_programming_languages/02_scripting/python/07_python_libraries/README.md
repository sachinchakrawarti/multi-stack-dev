# 07 - Python Libraries

## Overview
This section covers essential Python libraries for scientific computing, data analysis, visualization, and machine learning.

## Included Libraries

### Scientific Computing
| Library | Description |
|---------|-------------|
| **NumPy** | Numerical computing with arrays and matrices |
| **SciPy** | Scientific computing and algorithms |
| **SymPy** | Symbolic mathematics and algebra |
| **Pandas** | Data manipulation and analysis |

### Visualization
| Library | Description |
|---------|-------------|
| **Matplotlib** | 2D and 3D visualization |
| **Seaborn** | Statistical data visualization |
| **Plotly** | Interactive web-based visualization |

### Machine Learning & AI
| Library | Description |
|---------|-------------|
| **Scikit-learn** | Machine learning algorithms |
| **TensorFlow** | Deep learning framework |
| **PyTorch** | Deep learning framework |
| **Keras** | High-level neural networks API |

### Image Processing
| Library | Description |
|---------|-------------|
| **OpenCV** | Computer vision and image processing |
| **Scikit-image** | Image processing and computer vision |

### Statistics
| Library | Description |
|---------|-------------|
| **Statsmodels** | Statistical modeling and testing |

## Structure
Each library follows the same structure:
```
lib_name/
├── 01_theory/      # Documentation and concepts
├── 02_examples/    # Code examples
├── 03_notebook/    # Jupyter notebooks
└── 04_projects/    # Practical projects
```

## Learning Path
1. Start with **NumPy** (foundation for all scientific libraries)
2. Move to **Pandas** (data manipulation)
3. Learn **Matplotlib** (visualization)
4. Explore **SciPy** (advanced scientific computing)
5. Dive into **SymPy** (symbolic math)
6. Discover statistical libraries (**Seaborn**, **Statsmodels**)
7. Master interactive visualization (**Plotly**)
8. Explore image processing (**Scikit-image**, **OpenCV**)
9. Dive into machine learning (**Scikit-learn**)
10. Advanced deep learning (**TensorFlow**, **PyTorch**, **Keras**)

## Prerequisites
- Basic Python knowledge
- Understanding of fundamentals (covered in sections 01-06)
