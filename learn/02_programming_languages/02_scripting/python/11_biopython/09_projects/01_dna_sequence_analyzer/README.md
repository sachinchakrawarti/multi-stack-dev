# DNA Sequence Analyzer

Biopython-based DNA analysis tool.

## Install
pip install -r requirements.txt

## Usage
python dna_analyzer.py --make-samples
python dna_analyzer.py -f sample_data/sample.fasta --min-orf 30
python dna_analyzer.py -g sample_data/sample.gb -o sample_data/report.txt
python dna_analyzer.py -s ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG
python nootbook_script.py
