# 📚 What is Quantum Computing?

Quantum Computing is a new paradigm of computation that uses the principles of **quantum mechanics** to process information.

Unlike classical computers, which use **bits (0 or 1)**, quantum computers use **qubits**, which can exist in multiple states simultaneously through **superposition** and can be connected through **entanglement**.

This allows certain problems to be solved much faster than on classical computers.
