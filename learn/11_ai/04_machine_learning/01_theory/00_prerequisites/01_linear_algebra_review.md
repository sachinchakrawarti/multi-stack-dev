# Linear Algebra Review

## Why Learn Linear Algebra?
- Foundation of Machine Learning
- Used to represent data, models, and transformations
- Essential for deep learning, PCA, recommendation systems, and computer vision

---

## Prerequisites
- Basic algebra
- Coordinate geometry
- Functions

---

## Scalars
- A single number
- Example:
  ```text
  x = 5
  learning_rate = 0.01
  ```

---

## Vectors
- Ordered list of numbers
- Represents a point or direction

Example:

```text
v = [2, 4, 6]
```

Applications:
- Feature vectors
- Word embeddings
- Images

---

## Matrices

A rectangular grid of numbers.

Example:

```text
A =
[1 2]
[3 4]
```

Applications:
- Datasets
- Image pixels
- Neural network weights
